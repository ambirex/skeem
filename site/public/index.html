Agents should look facts up, not make them up.

skeem is a relational-aware CLI and MCP server for headless backends — Directus, PocketBase, NocoDB, Strapi — and the world's public reference datasets. Stable JSON envelopes, schema-aware writes, claims, idempotency, and provenance, built for AI agents.

npm install -g skeem

or run it with no install: npx skeem get items Q42 --adapter wikidata --json

Built for agents — CLI or MCP, your choice

Shell-native CLI

Any agent that can run a command can drive skeem. Lowest token overhead, composes with pipes and scripts. skeem tools --format anthropic even generates tool definitions from your live schema.

$ skeem create movies --enrich tmdb:movies:603 \
    --map externalIds.imdb=imdb_id --json

Or attach it as an MCP server

For Claude, Cursor, and any MCP client — the same engine over stdio, exposed as 18 verb-shaped tools.

$ claude mcp add skeem -- npx -y @skeems/mcp

Same engine, same JSON envelopes either way — including the typed error.code agents branch on.

Where it fits

vs. hand-rolled REST/SDK calls

One schema-aware command instead of bespoke glue, with idempotency, soft-delete, and provenance built in.

vs. your backend's own MCP

skeem spans backends and the world's reference datasets, adds a coordination layer raw APIs lack, and works as plain CLI or MCP.

What it is not

Not an ORM, not a migration tool, not a database client. It's an agent-facing data substrate.
