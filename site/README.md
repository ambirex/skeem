# skeem.brenty.dev

The marketing site for skeem. Static HTML/CSS/vanilla JS — no framework, no
build step. Deployed to Cloudflare Pages.

## Layout

```
site/
├── serve.mjs            # zero-dep local static server (npm run site:dev)
├── capture/             # the demo capture pipeline (dev-time only)
│   ├── capture.mjs        # boots the Directus fixture + runs real commands
│   ├── scenarios.mjs      # declarative scenario specs
│   └── sync-agent-files.mjs  # copies llms.txt / SKILL.md / og image into public/
└── public/              # exactly what Cloudflare Pages serves
    ├── index.html  styles.css  player.js  main.js  favicon.svg
    ├── scenarios/*.json   # committed, captured real CLI output
    ├── _headers  _redirects
    └── llms.txt  SKILL.md  og/  (generated by sync-agent-files)
```

## Develop

```bash
npm run site:dev        # serve site/public at http://localhost:8788
```

The terminal widget (`player.js`) replays the JSON files in
`public/scenarios/`. Those are real captured CLI output — never hand-edited.

## Refresh the demos

Re-record every scenario's real output (boots the shared Directus fixture and
hits the live public reference APIs):

```bash
npm run site:capture    # build → capture all scenarios → sync agent files
git diff site/public/scenarios/   # review (only capturedAt/durationMs should churn)
```

Re-capture a single scenario after a live-API hiccup:

```bash
node site/capture/capture.mjs --only enrich-create
```

Requirements: a prior `npm run build` (the script does it), `jq` (trims huge
reference payloads), and ~2-3 min the first time (the Directus fixture under
`test/.tmp/directus-smoke` provisions on first run; reused after). No API keys
— every scenario uses no-auth reference adapters. The capture asserts that no
fixture token or machine path leaks into the committed JSON.

## Deploy (Cloudflare Pages)

Git integration, no build step (scenario JSONs are committed):

- Root directory: `site`
- Build command: *(empty)*
- Output directory: `public`
- Build watch path: `site/*`
- Custom domain: `skeem.brenty.dev`

PRs that touch `site/` get a preview deploy automatically.
